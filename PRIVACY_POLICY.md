# Privacy Policy / 隐私政策

Last updated / 更新时间：2026-06-12

ThreadPilot for ChatGPT is a browser extension for improving long ChatGPT conversation reading and navigation.

ThreadPilot for ChatGPT 是一个浏览器扩展，用于改善 ChatGPT 网页端长对话的阅读和导航体验。

## Data collection / 数据收集

ThreadPilot does not collect, sell, transfer, or upload user data.

ThreadPilot 不收集、不出售、不转移，也不上传用户数据。

Your ChatGPT conversation content stays in your browser.

你的 ChatGPT 对话内容会留在浏览器本地，不会被插件上传。

## Local storage / 本地存储

ThreadPilot uses Chrome's `storage` permission to save local settings, including:

ThreadPilot 使用 Chrome 的 `storage` 权限保存本地设置，包括：

- navigator visibility / 导航条显示状态
- filter mode / 筛选模式
- navigator side and offset / 导航条位置和侧边距离
- AI reply folding preference / AI 回复折叠偏好
- collapsed reply height / 折叠保留高度
- native navigator hiding preference / 是否隐藏原生导航

These settings are used only for extension functionality.

这些设置仅用于提供扩展功能。

## Network requests / 网络请求

ThreadPilot does not make remote network requests for analytics, tracking, advertising, or data collection.

ThreadPilot 不会为了分析、追踪、广告或数据收集而发起远程网络请求。

Links inside the About page or website open only when the user clicks them.

关于页或官网中的链接只有在用户主动点击时才会打开。

如需反馈问题或建议，请使用 GitHub Issues：

https://github.com/billowssun/threadpilot-for-chatgpt/issues
